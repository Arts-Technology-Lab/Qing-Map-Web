# UI themes

Two complete chrome sets (badges + paper):

| Theme | Path | Look |
|---|---|---|
| **silver** (default) | `silver/` | Greyscale silver badges + white/silver paper |
| **bronze** | `bronze/` | Aged bronze badges + golden paper |

Switch theme in [`src/config.ts`](../../src/config.ts) (`UI_THEME`). No end-user toggle.
